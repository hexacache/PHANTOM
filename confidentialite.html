Politique de confidentialité

Informations sur les données et la vie privée des visiteurs.

Dernière mise à jour : 26 octobre 2026

1. Présentation du site

PHANTOM est un site consacré au jeu d'énigmes fictif OPÉRATION PHANTOM. Il permet notamment de consulter des documents de jeu et de saisir une réponse à une énigme.

2. Données traitées par le site

Le site ne propose actuellement ni création de compte, ni formulaire de contact. La réponse à l'énigme est vérifiée directement dans le navigateur et n'est pas envoyée à un serveur par le code de vérification du site.

Cette description concerne le fonctionnement du site lui-même ; elle ne signifie pas que l'hébergeur ne traite aucune donnée technique.

3. Hébergement et données techniques

Le site est hébergé par GitHub Pages, un service de GitHub. La documentation officielle de GitHub précise que l'adresse IP des visiteurs d'un site GitHub Pages est enregistrée et conservée à des fins de sécurité.

GitHub peut également traiter des données techniques conformément à ses propres règles et à sa déclaration de confidentialité. Pour connaître les traitements, les durées de conservation et les modalités applicables, consultez les documents officiels de GitHub.

Documentation GitHub Pages · Déclaration de confidentialité de GitHub

4. Cookies et traceurs

Le site n'intègre volontairement aucun outil tiers de publicité, de mesure d'audience ou de contenu embarqué. Aucun mécanisme de suivi propre au site n'est prévu dans son fonctionnement actuel.

Le fonctionnement technique de l'hébergement peut relever de traitements distincts effectués par GitHub. Cette page ne prétend pas certifier l'absence de tout cookie ou traitement technique du côté de l'hébergeur.

5. Liens externes

Cette page peut renvoyer vers la documentation de GitHub. Lorsque vous ouvrez un site externe, ses propres règles de confidentialité s'appliquent.

6. Modifications

Cette politique sera mise à jour si le fonctionnement du site change, notamment si des formulaires, des comptes, des statistiques ou de nouveaux services sont ajoutés.
